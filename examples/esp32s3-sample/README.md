# `esp32s3-sample`

This subproject (`examples/esp32s3-sample`) is the template generated by `esp-generate` for the ESP32-S3 (with `esp-hal`, `embassy`, `defmt`, and the `zed` tooling option). It already targets `#![no_std]`, runs on `esp-rtos`, and includes the `defmt` descriptor expected by many ESP flashers.

## What’s inside?

- `Cargo.toml`: defines the `esp32s3-sample` binary and pulls in `esp-hal`, `esp-rtos`, `embassy`, `defmt`, and the supporting ecosystem crates.
- `src/bin/main.rs`: an async task that starts the RTOS, prints “Hello world!” every second via `defmt`, and documents the generator arguments used to create the project.
- `.cargo/`, `.clippy.toml`, `rust-toolchain.toml`, and `build.rs`: boilerplate from `esp-generate` to pin the toolchain and lint rules.

## How to use it

1. Install the ESP toolchain:
   ```sh
   cargo install espup
   espup install
   ```
   That adds the `xtensa-esp` targets and tools like `espflash`, `esp-config`, and `probe-rs` needed to build and flash.

2. Build the example:
   ```sh
   cargo build --example esp32s3-sample --release
   ```

3. Flash it to your ESP32-S3 (replace `/dev/ttyUSB0` with your port):
   ```sh
   cargo espflash --example esp32s3-sample --release /dev/ttyUSB0
   ```
   To see `defmt` output, use `espflash` with the built-in `defmt` support or pipe the binary through `defmt-print`.

4. Monitor the serial output without `defmt` using `minicom`/`picocom` at 115200 bps, or run `cargo espflash --monitor --example ...`.

## Integrating the CST9217 driver

Use this template as a starting point for your touch demo:

- Replace the loop in `src/bin/main.rs` with the CST9217 flow you prepared in `examples/esp32s3-touch`.
- Add your touch/controller initialization there, including the I²C bus and reset/INT handling (GPIO15/14/40/11 in your design).
- Keep `cst9217 = { path = "../..", features = ["defmt"] }` in this crate’s `Cargo.toml` so you can reuse the driver code directly.

## Need a different demo?

If you prefer a fully wired touch example, take a look at `examples/esp32s3-touch` in the root workspace. That binary already resets the CST9217, reads touches, and logs coordinates via `defmt`.
